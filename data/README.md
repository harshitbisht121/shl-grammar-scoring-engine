# Dataset access

The competition dataset is intentionally not included in this repository.

If you are authorized to participate, obtain it from the official SHL Hiring Assessment 2026 Kaggle competition and attach it to your Kaggle notebook. The notebook expects the `Dataset_Final` layout with `train.csv`, `test.csv`, `sample_submission.csv`, and `train/` and `test/` audio folders.

Do not copy the data, audio, transcript cache, derived feature tables, or submission CSVs into this repository unless the official competition terms explicitly permit it.
